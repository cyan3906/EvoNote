Markdown 写法说明

用少量符号整理笔记结构：标题、列表、嵌套列表、待办和代码块都可以直接写。

标题

# 一级标题
## 二级标题
### 三级标题

无序列表

- 第一件事
- 第二件事
- 第三件事

列表套列表

- 学习计划
  - 看文档
  - 写示例
    - 记录问题
- 明天复盘

子列表前面输入两个空格。编辑器里按 Tab 也会插入两个空格。

有序列表

1. 打开笔记
2. 写下想法
3. 保存整理

待办

- [ ] 还没完成
- [x] 已经完成

引用

> 这是一段引用
> 可以连续写多行

行内代码

使用 `console.log()` 做调试。

代码块

```js
function hello() {
  console.log("Evonote");
}
```

加粗和斜体

**重点内容**
*补充说明*
